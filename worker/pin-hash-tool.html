PIN-Hash für den Cloudflare-Worker erzeugen

Hier wird aus deiner PIN ein Hash berechnet. Nur dieser Hash kommt später als Cloudflare-Secret in den Worker — deine PIN selbst wird nirgends gespeichert oder verschickt.

✓ Läuft vollständig in deinem Browser — keine Internetverbindung nötig

Wichtig: Diese Seite jetzt schließen. Den Hash nirgendwo in dein Projekt schreiben — er gehört ausschließlich in das Cloudflare-Secret.

Zusätzlich brauchst du einmalig ein Secret namens AUTH_SECRET.
