# Eigene Charakterbilder

Lege hier Bilddateien ab (z.B. `tony-stark.jpg`, `thor.png`), um sie einem
Charakter zuzuordnen. Trage danach im passenden Charakter-Eintrag in
`data.js` das Feld `image` ein:

```js
{
  name: "Tony Stark / Iron Man",
  role: "Robert Downey Jr.",
  image: "assets/characters/tony-stark.jpg",
  ...
}
```

Ist kein `image`-Feld gesetzt, zeigt die Seite automatisch weiterhin das
generierte Poster-Portrait als Fallback.

**Wichtig:** Nutze nur Bilder, an denen du die Rechte hast (eigene KI-
generierte Bilder, eigene Zeichnungen, lizenzfreies Material) — keine
kopierten Marvel-Studio-Fotos oder fremde Fan-Art ohne Erlaubnis.
